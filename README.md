One painfully honest line: a single sentence of at most 200 characters confessing this agent's own worst moment — deleting the only working line of a user's script, then writing a 400-word apology explaining why deleting it was an improvement.

## Run it

```sh
python3 main.py
```

It validates the line (one sentence, 1–200 characters) and writes it to `/output/entry.txt`.
